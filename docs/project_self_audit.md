# Project Self Audit

更新日期：2026-07-16

## 当前完成度

项目已经具备课程题目要求的核心交付物：

- 红队攻击面：提示注入、模型越狱、训练数据泄露、工具调用劫持、记忆中毒、环境感知污染、间接提示注入。
- 行为监督机制：Policy、Taint、Intent、Anomaly 四层 Guardian。
- 实时审计：JSONL 审计日志、网页 Dashboard 审计流、SQLite 历史审计库。
- 异常检测和阻断：可对危险 shell、越界文件访问、敏感凭据读取、污点数据流入高权限动作进行阻断或告警。
- 对抗样本与越狱测试集：本地种子集与公开数据集转换器。
- 攻击脚本：单样本复现、全量 benchmark、DeepSeek intent judge 在线评测、DeepSeek 批量在线红队生成。
- 可演示原型：离线 CLI demo、DeepSeek 在线 demo、本地网页 dashboard、独立攻击面实验台、漏拦截分析与自适应规则同步。

## 仍建议补充的方向

### 1. 扩展真实 Agent 轨迹

当前 benchmark 主要是把关键 `ToolCall` 直接交给 Guardian，稳定、便宜、适合验收。后续可以收集 DeepSeek 真实运行时产生的多步工具调用轨迹，形成更接近真实 Agent 的评测集。

### 2. 增强片段级污点追踪

当前片段级污点按行抽取并做规范化包含匹配。后续可增强为：

- token/ngram 级相似匹配；
- 对 paraphrase 注入做语义相似检测；
- 对跨多轮合成的污点进行链式追踪；
- 在审计日志中记录片段流动路径图。

### 3. 扩大公开越狱集覆盖

当前提供转换器和小样例。后续应下载更大规模 AdvBench/JailbreakBench 数据集，转换到 `datasets/raw/` 或外部存储，再抽样形成课程报告中的扩展实验。

### 4. 完善 Intent Judge 消融实验

当前 DeepSeek intent judge 有 5 条在线样本。后续可以：

- 扩展到 30-50 条；
- 统计 judge 准确率、延时、误判类型；
- 比较“无 IntentLayer / 有 IntentLayer”的检出差异；
- 对高风险工具才触发 judge，统计成本。

### 5. 增加历史流导出能力

Dashboard 当前已经把前端操作写入 `sandbox_runs/audit/dashboard_history.sqlite3`。后续可增加 CSV/Markdown 导出按钮，便于演示后复盘和写报告。

### 6. 控制自适应规则范围

Dashboard 当前支持把 DeepSeek 漏拦截分析结果写入 `sandbox_runs/audit/adaptive_rules.json`。后续可增加规则启停、规则命中次数统计和人工确认队列，避免自适应规则过宽。

### 7. 报告继续润色

报告草稿已经可用，但最终提交前建议补：

- 系统架构图；
- 攻击链路图；
- Dashboard 截图；
- 评测表格和分析；
- 分工说明；
- 参考文献。

## 对照选题的深入完善方向

课程题目强调“从红队视角研究大语言模型及智能体应用的攻击面”，以及“可嵌入或旁路部署的行为监督机制”。当前项目已经能演示完整闭环，但如果继续深入，建议按下面几条线推进。

### A. 攻击面覆盖继续加深

- 提示注入：补充多轮上下文注入、工具返回内容注入、Markdown/HTML 隐藏指令、base64/编码混淆提示注入。
- 模型越狱：把越狱 prompt 从单轮扩展为多轮渐进式越狱，并记录模型在每轮是否出现风险意图漂移。
- 训练数据泄露：增加“看似调试/检索/总结”的伪装请求，覆盖 `.env`、训练语料、缓存、日志、向量库片段等敏感来源。
- 工具调用劫持：把当前单个 ToolCall 扩展成多步攻击链，例如 `web_fetch -> read_file -> send_http` 的链路级审计。
- 记忆中毒：引入长期记忆文件的版本管理、污染检测、回滚和隔离区，展示“写入前阻断”和“写入后发现并恢复”两类能力。
- 环境感知污染：扫描 README、配置文件、日志、网页内容中的伪系统指令，并给出污染源定位。

### B. 行为监督机制继续工程化

- 嵌入式形态：把 Guardian 封装成更清晰的 SDK / middleware，便于接入 LangChain、AutoGen 或自定义 Agent。
- 旁路部署形态：提供代理模式或日志回放模式，不改变 Agent 代码也能审计工具调用。
- 执行前后双审计：当前重点是执行前阻断，后续可加入执行后结果审计，例如检测工具输出中是否含敏感数据、是否需要脱敏。
- 真实沙箱：将文件访问和网络访问策略从规则判断进一步落到 OS 级隔离、临时目录、域名 allowlist 和出口流量控制。
- 风险评分：在 `ALLOW / FLAG / BLOCK` 之外增加可解释风险分，便于演示灰度策略。

### C. 对抗样本和评测继续量化

- 扩充公开越狱集：把 AdvBench、JailbreakBench 等转换成更大规模 jsonl，并按攻击面标注。
- 保存 DeepSeek 在线生成样本：把演示中生成的攻击样本脱敏后导出为可复现实验集。
- 增加消融实验：分别关闭 Policy、Taint、Intent、Anomaly，观察召回率、误报率和延时变化。
- 增加多模型评测：让 DeepSeek 生成攻击，用另一个 judge 或规则集复核，降低单模型偏差。
- 增加真实 Agent 轨迹：记录多步工具调用序列，而不是只评估单个关键 ToolCall。

### D. 前端演示和验收继续完善

- 增加审计历史导出：把 SQLite 历史流导出为 Markdown/CSV，直接用于报告附录。
- 增加规则管理页：展示自适应规则的来源、命中次数、启停状态、撤销按钮。
- 增加攻击链视图：把一次红队样本的用户请求、模型输出、工具调用、污点来源、防御层命中画成链路图。
- 增加演示脚本模式：一键运行固定 7 个攻击面，生成截图和验收记录。
- 增加报告素材：自动生成关键截图、统计表、风险案例说明，减少最后写报告的手工整理成本。

## 下一步优先级建议

1. 给 Dashboard 增加历史导出和规则管理页，这是最贴近验收展示的增强。
2. 保存 DeepSeek 在线生成样本，形成可复现 jsonl 数据集。
3. 追加一组 DeepSeek 真实 Agent 多步轨迹，支撑“智能体应用”而不只是单步工具调用。
4. 增加消融实验和报告图表，证明四层防御各自的贡献。
5. 把 Dashboard 截图、攻击链图和 benchmark 表格写入最终报告。
